Two near-identical pictures, side by side. Find every difference on the right
before the clock runs out. Three original hand-drawn scenes, drawn with the
Canvas 2D API — no image files, no network, everything is code.

- **Level 1 — Sunny Garden** (8 differences): a busy garden with flowers,
  a pond, a fence, butterflies and bees. The easy warm-up.
- **Level 2 — Cozy Kitchen** (9 differences): jars, a clock, a kettle, a cat
  and a fruit bowl. Look closer — the changes hide in the clutter.
- **Level 3 — Space Station** (10 differences): stars, control panels, an
  astronaut and a robot. The subtlest set.

Click the right picture to mark a difference (a green circle + check pops in
with a chime). A wrong click costs 5 seconds. Each level gives you 3 minutes
and 3 hints — a hint briefly pulses the region of one difference you have not
found yet. Finish a level to earn stars by the time left.

Keyboard: **H** hint · **R** restart level · **N** next level · **M** mute.

## Run

```sh
# serve game/ with any static server, then open it in desktop Chrome
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```
